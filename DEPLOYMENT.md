# Deployment / Submission Configuration

This is a static Excel workbook project. It does not need a web server, cloud hosting, or runtime deployment.

## Release procedure
1. Upload the workbook and documentation to a public GitHub repository.
2. Confirm the workbook opens and formulas recalculate in Excel or Google Sheets.
3. Submit the repository URL in the internship portal.
4. Publish the LinkedIn project post.

## Rollback
Restore the last known-good workbook or revert the Git commit. Follow `docs/ROLLBACK_EVIDENCE.md`.

## Configuration
- Artifact: `Task6_Excel_Formulas_Workbook.xlsx`
- Hosting: GitHub repository (file storage/version history)
- Runtime dependencies: Microsoft Excel or Google Sheets
- Application secrets: none
